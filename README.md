# WordCatch — экранный переводчик

Наводишь мышь на английское слово, жмёшь хоткей и видишь перевод прямо у курсора. Если под курсором нет слова, тот же хоткей «замораживает» экран: выбираешь абзацы, и их перевод открывается в отдельном окне. Любое слово или фразу можно одной закладкой отправить карточкой в Obsidian (плагин Spaced Repetition).

## Запуск
**Проще всего:** скачай архив `WordCatch-…-win64.zip` со страницы [Releases](https://github.com/Jabhah/wordcatch/releases), распакуй куда удобно (например, в `Документы`) и запусти `WordCatch\WordCatch.exe`. Python не нужен, программа появится в трее. Файлы в папке `_internal` рядом с exe не удаляй, без них программа не запустится. Exe не подписан, поэтому Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажми «Подробнее» → «Выполнить в любом случае».

**Обновление:** распакуй новую версию поверх старой папки (или в новое место). Ключ DeepL и настройки сохранятся, а автозапуск сам переключится на новый exe.

**Из исходников:** дважды кликни `run.bat`. При первом запуске он создаст `.venv` и поставит зависимости. После этого в трее (рядом с часами) появится значок **Aя**.

Для запуска вместе с Windows: правый клик по значку → «Запускать вместе с Windows».

## Управление
| Действие | Что происходит |
|---|---|
| **Alt + Q** или боковая кнопка мыши **«вперёд»** на слове | карточка слова |
| то же на месте без слова | экран замирает, абзацы обведены |
| клик по абзацу / рамка мышью | выбрать (можно несколько), `Ctrl+A` — все |
| **Enter** или правый клик | перевести выбранное (ничего не выбрано — весь экран) |
| двойной клик по абзацу | сразу перевести только его |
| **Esc** | закрыть |

### Карточка слова (сверху вниз)
1. **В тексте**: весь абзац, где стоит слово (слово подсвечено), и под ним перевод абзаца. Длинный абзац обрезается до трёх предложений, полный открывается ссылкой «показать весь абзац».
2. **Слово**: базовая форма (`went → go`), транскрипция; для неправильных глаголов строка `go — went — gone` с подсвеченной текущей формой.
3. **Перевод слова**: значения по частям речи, ниже примеры из Tatoeba. Значения — «чипы»: клик выбирает, какие из них попадут в карточку (по умолчанию первые 3).
4. **Закладка** в правом верхнем углу: контур с плюсом — слова ещё нет в колоде, заливка — уже есть.

### Русский текст
Текст распознаётся сразу двумя пакетами Windows OCR: английским и русским, если русский установлен. Для строк, где больше кириллицы, берётся русский вариант, поэтому `привет` больше не превращается в `npuBeT`. Русское слово переводится **на английский** (`вернулись → вернуться`, «в этом тексте: returned»), а карточка пишется в том же виде, что и остальные: `to return:::вернуться`. Русские абзацы в окне перевода экрана тоже переводятся на английский.

### Окно перевода экрана
Две колонки «оригинал | перевод». Выдели слово или фразу в оригинале и нажми закладку в правом верхнем углу, чтобы сделать карточку. Двойной клик по слову открывает его подробную карточку.

## Карточки в Obsidian
Хранилище определяется само: берётся открытое хранилище из `%APPDATA%\obsidian\obsidian.json`. Другое можно указать в настройках.

### Автовыбор (кнопка «Авто» в карточке и окне перевода)
- **Включён**: значения отмечаются сами («в этом тексте» + первые N из словаря), в карточку идёт базовая форма, неправильные глаголы раскладываются на три карточки. Внизу видно, что именно уйдёт в Obsidian.
- **Выключен**: ничего не отмечено, внизу два поля — слово и перевод. Пишешь сам, клик по значению дописывает его в перевод. Сохраняется ровно то, что в полях, одной карточкой.

Состояние кнопки запоминается, его же можно поменять в настройках.

- Обычные слова → `English/Слова/Из переводчика.md`, тег `#flashcards/слова`, формат `resemble:::походить на, напоминать` (как в `Базовые.md`).
- Неправильные глаголы → `English/Слова/Неправильные глаголы.md`, тег `#flashcards/слова/неправильные` (отдельная ветка колоды), три карточки:
  ```
  go:::ходить, идти, ездить (V1: go — went — gone)
  went:::пошёл (V2 от go)
  gone:::ушедший (V3 от go)
  ```
  В настройках можно переключить на одну карточку `go — went — gone:::…`.
- Дубли ищутся во всех заметках папки `English/Слова`: если слово уже есть, оно не добавляется второй раз.

## Откуда перевод
| Что | Источник | Ключ |
|---|---|---|
| значения слова, транскрипция, базовая форма | Wiktionary (англ.), русские переводы по значениям | не нужен |
| примеры | Tatoeba, англо-русские пары предложений | не нужен |
| перевод абзацев и экрана | **DeepL API Free**, если указан ключ, иначе MyMemory | DeepL — бесплатный |
| текст на экране | встроенный Windows OCR | — |

**Советую добавить ключ DeepL** (настройки → «Ключ DeepL API» → «Проверить»): регистрация на deepl.com/pro-api, тариф *DeepL API Free* даёт 500 000 символов в месяц без рекламы (DeepL может попросить карту для проверки, но бесплатный тариф ничего не списывает). С ключом:
- перевод заметно точнее;
- в карточке слова появляется **«в этом тексте: …»**: как DeepL перевёл слово именно в этом абзаце, и это слово подсвечено в переводе;
- формы V2/V3 неправильных глаголов в карточках получают настоящий перевод (`went → пошёл`). Без ключа там стоит подпись «прошедшее время от …».

Без ключа работает MyMemory: 5 000 символов в день (50 000, если указать e-mail в настройках). Качество у него заметно ниже.

Все ответы кешируются в `%APPDATA%\WordCatch\cache.db`, поэтому повторный запрос того же слова мгновенный и не тратит лимит. Настройки лежат в `%APPDATA%\WordCatch\config.json`.

## Если что-то не так
- **«Не установлен английский пакет распознавания»**: Параметры → Время и язык → Язык и регион → добавить English (United States).
- **Хоткей не срабатывает**: возможно, его занимает другая программа. Смени его в настройках (например `ctrl+alt+e` или `f8`).
- **Мелкий текст распознаётся плохо**: увеличь `ocr_scale` в `config.json` (по умолчанию 2.0).

## Где лежат твои данные
Ключ DeepL, e-mail, путь к хранилищу и кеш переводов хранятся в `%APPDATA%\WordCatch\`. Доступ есть только у тебя...

Сам ключ DeepL лежит не в `config.json`, а в **диспетчере учётных данных Windows** (Панель управления → Диспетчер учётных данных → Учётные данные Windows → `deepl_key@WordCatch`). Вводишь его один раз: он переживёт обновление программы, сброс или порчу настроек. Если `config.json` окажется повреждён, программа отложит его в `config.broken-….json` и не станет молча затирать.

## Сборка exe
```
.venv\Scripts\python -m pip install pyinstaller
.venv\Scripts\python build.py
```
Получится папка `dist\WordCatch\` (exe + `_internal`, около 140 МБ) и архив `dist\WordCatch-<версия>-win64.zip` для релиза (около 70 МБ). Сборка в папку, а не в один файл: так exe не распаковывает себя во временную папку при каждом запуске и стартует за полсекунды. Проверить, что внутри exe работают OCR, словари и доступ к ключу: `WordCatch.exe --selftest out.txt`.

## Разработка
```
.venv\Scripts\python -m pytest tests
```
Структура: `wordcatch/ocr.py` (Windows OCR), `layout.py` (слово под курсором, абзацы), `translate/` (Wiktionary, DeepL, MyMemory, Tatoeba, кеш), `irregular.py` + `data/irregular_verbs.json`, `obsidian.py` + `cards.py` (карточки), `ui/` (окна), `app.py` (трей и хоткеи).

## Чужие данные в проекте
- `tests/fixtures/wikt_*.json` — статьи [Wiktionary](https://en.wiktionary.org), лицензия CC BY-SA 4.0.
- `tests/fixtures/tatoeba_*.json` — предложения [Tatoeba](https://tatoeba.org), лицензия CC BY 2.0 FR.
- `tests/fixtures/mymemory_text.json` — пример ответа MyMemory API.

Программа обращается к этим сервисам и к DeepL через их публичные API и показывает источник внизу карточки.
